# Cutest Picture — make.fun entry (cutest-picture-01)

A round baby kitten with huge sparkling eyes, drawn procedurally in
`main.ts` (Node 22, standard library only). No image files, no network, no
randomness: the program rasterizes the kitten from fixed constants and
writes a hand-encoded PNG to `/output/entry.png`, byte-identical on every
run.

The kitten: oversized round head, huge glossy eyes with highlights, pink
inner ears, a tiny bow, blush and whiskers, a pink bell collar, little paws,
hearts and sparkles on a soft pastel background — cute at one glance, and
still clear at thumbnail size.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
